# 📊 E-Commerce Sales Analysis Dashboard using Tableau

## Project Overview
Developed an interactive E-Commerce Sales Analysis Dashboard using Tableau to analyze sales performance, profitability, product categories, and monthly sales trends.

## Tools & Technologies
- Tableau
- Microsoft Excel
- Kaggle Dataset

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Features
- Sales Analysis by Category
- Monthly Sales Trend
- Top 10 Sub-Categories by Sales
- State-wise Sales Analysis
- Interactive Category and Date Filters

## Objective
To analyze e-commerce sales data, identify business trends, evaluate product performance, and support data-driven decision-making.

## Dataset
Source: Kaggle – E-Commerce Sales Dataset
